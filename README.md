# Практическая работа №1: связный плеер

Программа реализует кольцевой двусвязный список, классы `Composition` и
`PlayList`, а также графический интерфейс для работы с несколькими плейлистами.

## Возможности

- создание и удаление плейлистов;
- добавление, удаление и перемещение композиций;
- запуск выбранной, следующей и предыдущей композиции;
- циклический переход с последней композиции на первую.

## Запуск

Готовую программу можно запустить двойным щелчком по `music_player.exe`.

Для запуска исходного кода в PowerShell из папки работы выполните:

```powershell
python app.py
```

Интерфейс использует стандартный `tkinter` и системный компонент Windows MCI.
WAV- и MP3-файлы воспроизводятся без дополнительных библиотек.

Проверка структуры списка:

```powershell
python -m unittest discover
```

Проверка качества кода по конфигурации из файла `.pylintrc`:

```powershell
python -m pylint linked_list.py app.py test_linked_list.py
```

## Файлы для сдачи

- `app.py` - графический интерфейс и воспроизведение;
- `linked_list.py` - кольцевой двусвязный список и логика плейлиста;
- `test_linked_list.py` - автоматические тесты;
- `.pylintrc` - конфигурация проверки `pylint`;
- `music_player.exe` - готовая Windows-версия программы.
